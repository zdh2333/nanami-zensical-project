Nanami's Zensical 部署实战教程 😸¶

本教程记录了我和老大如何在一台 MacBook 上，从零开始部署并成功运行 Zensical 项目的全过程。

🛠 准备阶段¶

  1. 清理空间：清理了不常用的 App 和缓存，腾出 2GB+ 空间。
  2. 环境安装：
  3. Rust: 安装了最新的编译器 (rustc)。
  4. uv: 安装了现代 Python 包管理工具，用于管理复杂的依赖。

🚀 部署挑战 (Zensical)¶

在部署过程中，我们遇到了几个硬核问题： - 路径 Panic: Zensical 核心对配置路径极其敏感，少一个字段就会崩溃。 - 模板缺失: 官方 new 命令没能自动生成 UI 模板。

💡 解决方案 (猫式思维)¶

  1. 暴力注入配置: 手动编写了符合预期的 zensical.toml。
  2. 模板搬运: 从源码的 bootstrap 和 tmp/ui 中强行提取了 templates 骨架。
  3. 环境同步: 使用 uv run maturin develop 强行将 Rust 核心绑定到 Python。

📖 总结¶

不要被报错吓倒！当官方命令失效时，直接看源码、改配置、挪文件。
